# 部署与安全需求测试报告

执行环境：Orca 内置浏览器 + Orca 管理终端启动 Python 3.12 服务；Docker Compose 使用 `ADMIN_PASSWORD`、`SESSION_SECRET` 环境变量校验配置。

## 用例结果

| 用例 | 结果 | 证据 |
|---|---|---|
| TC-21 | ✅ 通过 | 停止并重新启动服务后 `/private/tmp/signal-desk-e2e/blog.db` 中项目和游戏仍可从首页访问 |
| TC-22 | ✅ 通过 | 在 Orca 页面内嵌 390x844 iframe 实测 `scrollWidth=375`、`noHorizontalScroll=true`、卡片单列 |
| TC-23 | ✅ 通过 | 390px iframe 中编辑表单为单列；聚焦标题输入得到 cyan border 与 2px box-shadow |
| TC-24 | ✅ 通过 | 单元测试验证签名 Cookie 篡改被拒绝；生产 Cookie 含 Secure 标志 |
| TC-25 | ❌ 不通过（BUG-002） | 超过 256KB 的请求进入 413 分支，但 `send_error` 使用中文 reason phrase 触发 UnicodeEncodeError，客户端收到连接失败 |
| TC-26 | ✅ 通过 | `/games/%2e%2e/app.py/play` 被规范化后返回 404，不读取项目外文件 |
| TC-27 | ✅ 通过 | 生产环境缺少密钥或使用默认密钥时启动退出；强密钥配置通过校验 |

## 部署配置补充

`docker compose config` 在缺少密钥时按预期拒绝插值；提供测试密钥后配置成功生成，数据卷映射到 `/data`，端口映射为 `8001:8000`。
