# Signal Desk 需求拆解与测试用例

## 需求拆解

| 类别 | 需求点 | 覆盖用例 |
|---|---|---|
| 状态机 | 文章草稿/已发布与发布、撤回 | TC-07、TC-08、TC-09 |
| 状态机 | 项目进行中/暂停/归档，归档不公开 | TC-12、TC-13 |
| 状态机 | 游戏草稿/已发布与静态包约束 | TC-15、TC-16 |
| 权限 | 访客可浏览公开内容、不能进入后台 | TC-01、TC-02、TC-03、TC-04、TC-05、TC-06 |
| 权限 | 管理员登录后可进入概览和三类管理页 | TC-17 |
| 字段规则 | 文章必填、slug、标签、正文 Markdown、外链安全 | TC-07、TC-10、TC-11 |
| 字段规则 | 项目 GitHub/Demo 外链与精选 | TC-12、TC-14 |
| 字段规则 | 游戏 slug 必须有静态包、源码外链 | TC-15、TC-16 |
| 特殊交互 | 登录失败提示、退出、CSRF、密码修改 | TC-17、TC-18、TC-19、TC-20 |
| 业务流程 | 创建文章并发布后公开可见 | TC-07、TC-08、TC-09 |
| 业务流程 | 项目保存 GitHub 后公开页可打开 | TC-12、TC-14 |
| 业务流程 | 游戏登记后从详情页运行静态包 | TC-15、TC-16 |
| 业务流程 | 服务重启后 SQLite 数据保留 | TC-21 |
| 响应式/无障碍 | 390px 无横向滚动、表单可用、焦点可见 | TC-22、TC-23 |
| 异常/安全 | 伪造会话、超大请求、限流、路径穿越 | TC-24、TC-25、TC-26、TC-27 |

## 正式用例

### 1. 公开访客页面

| 用例编号 | 测试项 | 前置条件 | 测试步骤 | 预期结果 | 优先级 | 测试类型 |
|---|---|---|---|---|---|---|
| TC-01 | 首页展示三类内容 | 服务已启动且存在种子文章、项目、游戏 | 打开 `/` | 显示个人定位、最新文章、精选项目、可玩的游戏；导航可到文章/项目/游戏/关于 | 高 | 正例 |
| TC-02 | 文章列表与详情 | 首页可用 | 打开 `/blog`，点击种子文章 | 列表显示文章卡片；详情显示标题、摘要、正文、标签和返回列表链接 | 高 | 正例 |
| TC-03 | 项目列表与详情 | 首页可用 | 打开 `/projects`，点击项目；点击 GitHub | 列表和详情显示项目元数据；GitHub 链接为外部 HTTP(S) 链接并可打开 | 高 | 正例 |
| TC-04 | 游戏列表、详情与运行页 | 存在 `games/signal-runner/index.html` | 打开 `/games`，进入 Signal Runner 详情，点击开始游戏 | 显示玩法和操作方式；运行页返回静态游戏包且可见游戏 UI | 高 | 正例 |
| TC-05 | 访客访问后台被拦截 | 未登录 | 打开 `/admin`、`/admin/posts` | 重定向到 `/admin/login`，不展示后台内容 | 高 | 权限 |
| TC-06 | 不存在或未公开内容不可见 | 服务已启动 | 打开不存在 slug、归档项目、草稿文章/游戏 URL | 返回 404 或不出现在公开列表，页面不泄露后台数据 | 中 | 反例 |

### 2. 管理员文章流程

| 用例编号 | 测试项 | 前置条件 | 测试步骤 | 预期结果 | 优先级 | 测试类型 |
|---|---|---|---|---|---|---|
| TC-07 | 默认种子账号登录 | `admin` / `test-password` | 打开 `/admin/login`，输入账号密码并提交 | 重定向 `/admin`，显示后台概览 | 高 | 正例 |
| TC-08 | 创建并发布文章 | 已登录管理员 | 打开新建文章，填写标题、摘要、正文、标签，状态选“已发布”，保存 | 返回文章管理列表；新文章显示已发布；公开 `/blog`、首页和 `/blog/<slug>` 都可见 | 高 | 正例 |
| TC-09 | 发布与撤回状态流转 | 已有一篇已发布文章 | 编辑并改为草稿保存，再改回已发布 | 草稿期间公开详情不可见；重新发布后可见；重新发布时间更新 | 高 | 状态机 |
| TC-10 | 文章必填与 slug 校验 | 已登录 | 新建文章留空标题或摘要提交；再使用 `../bad` 作为 slug 提交 | 页面出现可见错误提示并拒绝保存；不产生非法路径 | 高 | 反例 |
| TC-11 | Markdown 安全渲染 | 已登录 | 发布正文含标题、列表、代码块及 `<script>alert(1)</script>` 的文章 | Markdown 结构渲染；脚本作为文本转义，不执行 | 高 | 边界 |

### 3. 项目流程

| 用例编号 | 测试项 | 前置条件 | 测试步骤 | 预期结果 | 优先级 | 测试类型 |
|---|---|---|---|---|---|---|
| TC-12 | 创建项目并保存链接 | 已登录 | 新建项目填写名称、简介、技术栈、GitHub `https://github.com/example/repo`、Demo `https://example.com`，状态进行中并精选 | 列表出现项目；公开详情显示技术栈和两个链接；首页显示精选项目 | 高 | 正例 |
| TC-13 | 归档项目不公开 | 已有项目 | 编辑状态为归档并保存；打开公开列表和详情 | 归档项目从公开列表移除，详情返回 404 | 高 | 状态机 |
| TC-14 | 项目外链安全校验 | 已登录 | 填入 `javascript:alert(1)` 作为 GitHub 或 Demo 并提交 | 页面出现外链协议错误提示并拒绝保存 | 高 | 反例 |

### 4. 游戏流程

| 用例编号 | 测试项 | 前置条件 | 测试步骤 | 预期结果 | 优先级 | 测试类型 |
|---|---|---|---|---|---|---|
| TC-15 | 游戏静态包约束 | 已登录；存在 `games/signal-runner/index.html` | 新建游戏使用 slug `signal-runner` 发布；再用不存在 slug `missing-game` 发布 | 已存在包可保存；不存在包时页面给出静态包错误并拒绝保存 | 高 | 正例/反例 |
| TC-16 | 游戏草稿与运行隔离 | 已有已发布游戏 | 改为草稿并保存，访问详情/运行页；再改回发布 | 草稿不出现在公开页且运行页不可访问；重新发布后详情和运行页恢复 | 高 | 状态机 |

### 5. 管理、安全、部署与响应式

| 用例编号 | 测试项 | 前置条件 | 测试步骤 | 预期结果 | 优先级 | 测试类型 |
|---|---|---|---|---|---|---|
| TC-17 | 管理后台导航与列表 | 已登录 | 依次打开概览、文章、项目、游戏管理页 | 页面显示对应列表、创建入口和编辑入口 | 高 | 正例 |
| TC-18 | 登录失败提示与限流 | 未登录 | 连续提交错误密码 10 次 | 每次有错误提示；达到阈值后服务返回 429 或等价限流提示 | 中 | 异常场景 |
| TC-19 | 退出登录 | 已登录 | 提交退出 | 回到公开首页；再次访问 `/admin` 被重定向登录页 | 高 | 正例 |
| TC-20 | CSRF 与密码修改 | 已登录 | 直接提交缺少/错误 CSRF 的保存请求；再在密码页用不一致的新密码提交 | 请求被拒绝并显示会话失效；密码不一致时显示错误且不修改密码 | 高 | 安全/反例 |
| TC-21 | SQLite 持久化 | 已用 `DATA_DIR=/private/tmp/signal-desk-e2e` 启动并创建测试文章 | 停止服务后用同一环境重启，打开首页和后台列表 | 已创建内容仍存在；数据库文件位于挂载数据目录 | 高 | 异常场景 |
| TC-22 | 390px 响应式布局 | 浏览器可设置 viewport | 将 viewport 设为 390x844，打开首页、文章、后台表单 | `scrollWidth <= clientWidth`；内容无横向滚动；操作按钮可见 | 高 | 边界 |
| TC-23 | 390px 表单与焦点可见 | 已登录，viewport 390px | 打开文章编辑页；键盘 Tab 遍历输入和按钮 | 表单单列可用；焦点有可见轮廓；按钮可操作 | 高 | 无障碍 |
| TC-24 | 会话 Cookie 防篡改 | 已登录 | 修改 `signal_session` Cookie 任意字符后访问 `/admin` | 篡改 Cookie 无法进入后台，重定向登录页 | 高 | 安全 |
| TC-25 | 超大请求拒绝 | 服务已启动 | 向 POST 发送超过 256KB 的表单 | 返回 413 或等价“请求过大”响应，不写入数据 | 中 | 边界 |
| TC-26 | 路径穿越防护 | 服务已启动 | 访问 `/games/../app.py/play` 或非法 slug | 返回 404，不读取项目外文件 | 高 | 安全 |
| TC-27 | 生产配置拒绝默认密钥 | 未启动生产服务 | 使用生产环境且缺少或使用默认密码/Session Secret 启动 | 启动被拒绝并提示必须配置安全密钥 | 高 | 配置安全 |
